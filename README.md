E-LIBRARY MANAGEMENT SYSTEM

Windows quick start:
1. Extract the ZIP.
2. Install Python 3.10+ from https://www.python.org/downloads/.
3. Double-click START_APP.bat.
4. Open http://localhost:8501 if needed.

Features: searchable digital catalogue, category filter, e-book metadata and authorised reading links, reader registration, bookmark lists.
Database: elibrary.db is created automatically. Keep this file to retain records.
Important: this starter stores links and metadata, not copyrighted book files. Add only material you own or are authorised to share. Reader registration is a prototype, not secure login/authentication.
